# 참돔 트레이드

- 웹페이지: https://btypenine.github.io/chamdom/ — 바이낸스 선물 조종석(구글 로그인, 상태·위험·대응 버튼). 이전 화면(업비트·자세한 분석)은 `legacy.html`.
- `bot/binance_bot.py`: PC에서 실행하는 바이낸스 USDⓈ-M 선물 엔진(`start_binance.bat`). 이 저장소의 최신 코드를 10분마다 확인해 자동 업데이트합니다. 대시보드 대응 명령(멈춤·정리·본전 손절)과 승인·요청 연결도 이 엔진이 맡습니다.
- `bot/chamdom_bot.py`: 엔진이 함께 쓰는 공용 코드 + 업비트 봇. 운영자 PC의 업비트 자동매매는 2026-11-23 종료(친구용은 그대로).
- API 키와 연결 코드는 PC의 `bot_config.env` 에만 두고 이 저장소에는 절대 올리지 않습니다.
