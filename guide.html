CHAMDOM TRADE · 친구용

참돔 트레이드, 내 업비트 키로 시작하기

내 PC에서 내 업비트 계정으로 돌아가는 소액 자동매매 봇입니다. 키는 내 PC에만 저장되고, 폰에서는 대시보드로 상태를 보고 멈출 수 있습니다. 처음 설치는 30분 정도 걸립니다.

시작 전에 꼭 읽어 주세요
  • 수익을 보장하지 않습니다. 지금도 실험 중인 봇이라 손실이 날 수 있으니, 잃어도 괜찮은 소액으로만 쓰세요.
  • 업비트 키와 연결 코드는 비밀번호와 같습니다. 누구에게도(운영자 포함) 보내거나 캡처해 올리지 마세요.
  • 키를 만들 때 출금 권한은 절대 켜지 마세요. 그러면 키가 새더라도 돈이 밖으로 나갈 길은 없습니다.
  • 업비트 키는 등록한 IP에서만 주문이 됩니다. 그래서 항상 켜 두는 내 PC가 필요합니다. 폰만으로는 돌릴 수 없습니다.

1

PC 준비

  • 윈도우 PC 한 대를 계속 켜 둡니다. 회사·집 어디든 괜찮습니다.
  • 설정 → 시스템 → 전원에서 "절전 모드로 전환"을 안 함으로 바꿉니다. 화면 끄기는 그대로 둬도 됩니다.
  • 설정 → Windows 업데이트에서 업데이트를 일시 중지하거나 사용 시간을 설정해 밤사이 재부팅을 막습니다.
2

파이썬 설치

  1. python.org/downloads에서 최신 버전을 받아 실행합니다.
  2. 설치 첫 화면 맨 아래 "Add python.exe to PATH"를 꼭 체크하고 Install Now.
  3. 설치가 끝나면 윈도우키 + R → cmd → 엔터, 그리고 python --version을 입력합니다. Python 3.x.x처럼 숫자가 나오면 성공입니다.
숫자 없이 Python만 나오면: 설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭에서 python.exe, python3.exe 두 개를 끄고 명령 창을 새로 여세요.
3

봇 받기

친구용 봇 zip 받기
버튼이 안 되면 주소창에 직접: btypenine.github.io/chamdom/friend/chamdom_bot_friend.zip
  1. 받은 zip을 열어 안의 chamdom_bot 폴더를 C:\ 바로 아래로 옮깁니다. 최종 위치는 C:\chamdom_bot입니다.
  2. 파일 탐색기 보기 → 표시 → 파일 확장명을 켭니다. 이름 바꿀 때 실수를 막아 줍니다.
폴더 안: chamdom_bot.py · start_bot.bat · bot_config.env.example · README.txt
4

이 PC의 IP 확인

  1. 봇을 돌릴 그 PC에서 구글에 "내 IP"를 검색합니다.
  2. 나오는 숫자(예: 125.249.38.45)를 적어 둡니다. 다음 단계에서 업비트에 등록합니다.
다른 PC나 폰에서 확인한 IP는 다를 수 있습니다. 공유기를 껐다 켜면 IP가 바뀔 수 있는데, 그때는 업비트에서 IP만 다시 등록하면 됩니다.
5

업비트 Open API 키 만들기

필요한 것: 실명 인증과 2채널 인증이 된 업비트 계정, 원화를 넣어 둔 상태(케이뱅크 연결 계좌로 입금)
  1. PC 브라우저로 upbit.com에 로그인합니다.
  2. 오른쪽 위 My(마이페이지) → Open API 관리로 들어갑니다.
  3. 포켓 선택은 메인포켓 그대로 둡니다.
  4. 권한 선택에서 아래 세 개만 체크합니다.
자산조회 ✓주문조회 ✓주문하기 ✓포켓관리 출금조회출금하기입금조회입금하기
  1. IP 주소 등록 칸에 4단계에서 적은 IP를 입력합니다.
  2. 개인정보 수집 동의에 체크하고, "로봇이 아닙니다"를 확인한 뒤 Open API Key 발급받기를 누릅니다.
  3. 카카오페이나 네이버 등 휴대폰 인증 요청이 오면 승인합니다.
  4. Access Key와 Secret Key가 나옵니다. Secret Key는 이 화면에서 딱 한 번만 보입니다. 창을 닫기 전에 바로 7단계 설정 파일에 붙여 넣으세요.
지켜야 할 것
  • 출금하기·출금조회는 절대 체크하지 않습니다.
  • 키는 1년 동안 유효합니다. 만료되면 삭제하고 같은 방법으로 다시 만듭니다.
  • 키가 새었다고 생각되면 바로 같은 화면 아래 목록에서 삭제하세요. 즉시 무효가 됩니다.
  • 이미 갖고 있는 코인 중 봇이 절대 건드리면 안 되는 게 있으면 7단계 PROTECTED_COINS에 적습니다.
6

대시보드 로그인과 연결 코드

  1. 그 PC의 크롬으로 btypenine.github.io/chamdom에 들어가 구글로 로그인합니다. 내 계정 칸이 따로 생기고, 다른 사람의 정보는 보이지 않습니다.
  2. 맨 아래 PC 봇 연결 코드 → 열기 → 연결 코드 보기 → 코드 복사.
  3. 폰에서도 같은 주소로 같은 구글 계정에 로그인해 두세요. 크롬 메뉴의 홈 화면에 추가를 누르면 앱처럼 쓸 수 있습니다.
7

설정 파일 채우기

  1. C:\chamdom_bot에서 bot_config.env.example 이름을 bot_config.env로 바꿉니다(뒤의 .example만 지우기).
  2. 마우스 오른쪽 → 연결 프로그램 → 메모장으로 열어 아래 값을 채우고 저장합니다. = 뒤에 공백이나 따옴표 없이 붙여 넣습니다.
항목넣을 값
UPBIT_ACCESS_KEY5단계 Access Key
UPBIT_SECRET_KEY5단계 Secret Key
FIREBASE_LINK_CODE6단계 연결 코드 (길지만 한 줄로)
TRADE_MODEpaper로 시작 (모의매매, 실제 주문 없음)
BOT_BUDGET_KRW봇이 쓸 최대 원화. 기본 100000
DAILY_LOSS_LIMIT하루 손실이 여기 닿으면 다음 날 9시까지 매수 중지. 기본 30000
PROTECTED_COINS절대 사고팔지 않을 코인, 쉼표로 (예: BTC,ETH). 없으면 비움
DEVICE_NAME대시보드에 보일 PC 이름
ROLE, UPDATE_CHANNEL그대로 둡니다 (friend, stable)
저장 후 이름이 bot_config.env.txt로 바뀌지 않았는지 확인하세요. 바뀌었다면 .txt를 지웁니다.
8

실행

  1. C:\chamdom_bot\start_bot.bat을 더블클릭합니다. 처음에는 필요한 부품을 자동으로 설치합니다.
  2. 창에 아래와 비슷한 줄이 나오면 성공입니다.
웹페이지 계정 연결됨 (abc123…) · 기기: 내 PC
모드: 모의매매 (실제 주문 없음) · 거래 금지/숨김: 없음
사용자 구분: 친구용 · 업데이트 채널: stable
  • 처음에는 종목을 고르고 전략을 시험하느라 몇 분 걸립니다. 폰 대시보드에 "진행 중: 전략 백테스트…"가 보입니다.
  • 창은 닫지 말고 최소화하세요. 닫으면 봇이 멈춥니다. 오류로 꺼져도 15초 뒤 자동으로 다시 켜집니다.
  • 봇은 검증된 안정판이 나오면 스스로 받아서 재시작합니다. 직접 파일을 바꿀 일은 없습니다.
  • PC를 켤 때 자동 시작하려면: 윈도우키 + R → shell:startup → 열린 폴더에 start_bot.bat의 바로 가기를 넣습니다.
9

모의매매에서 실매매로

  1. 2~3일 모의매매로 돌리며 대시보드에서 거래, 승률, 실패 원인이 어떻게 쌓이는지 봅니다.
  2. 실제로 해 보고 싶으면 bot_config.env에서 TRADE_MODE=live로 바꾸고 저장합니다.
  3. 봇 창을 닫고 start_bot.bat을 다시 실행합니다. 시작 줄에 ★ 실매매 (실제 주문) ★이 보이면 적용된 것입니다.
실매매에서도 봇은 실전 검증을 통과한 규칙만 실제 돈으로 주문하고, 아직 검증 중인 규칙은 모의로 시험합니다. 그래서 처음에는 실제 주문이 적거나 없을 수 있습니다.
멈추고 싶을 때: 폰 대시보드의 일시정지(새 매수 중지) 또는 봇이 산 코인 모두 매도를 두 번 눌러 실행합니다. 완전히 끄려면 PC의 봇 창을 닫고, 키를 더 쓰지 않으려면 업비트에서 키를 삭제합니다.
10

문제 해결

화면에 보이는 것원인과 해결
no_authorization_ip이 PC의 IP가 업비트 키에 등록된 것과 다름 → 4단계로 IP 확인 후 업비트에서 IP 수정(또는 키 재발급)
invalid_access_key, jwt_verification키를 붙여 넣을 때 공백이 들어갔거나 일부가 잘림 → 설정 파일 다시 확인
연결 코드가 맞지 않거나 만료대시보드에서 연결 코드를 다시 복사해 FIREBASE_LINK_CODE에 넣고 재실행
설정 파일이 없습니다이름이 bot_config.env인지, C:\chamdom_bot 안에 있는지 확인
'python'은(는) 내부 또는 외부 명령…파이썬 설치 때 PATH 체크를 안 함 → 2단계 다시
폰에 "PC 봇 응답 없음"PC가 꺼졌거나 절전, 인터넷 끊김, 봇 창이 닫힘 → PC 확인
원화 잔고 부족업비트에 원화가 BOT_BUDGET_KRW 이상 있는지 확인
물어볼 때는 봇 창의 [오류]·[경고] 줄을 보내 주세요. 키나 연결 코드가 보이는 부분은 꼭 가리세요.
참돔 트레이드 · 각자 자기 PC, 자기 키, 자기 책임으로 쓰는 실험용 봇입니다.
