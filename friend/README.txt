참돔 트레이드 친구용 — 빠른 설치

1. python.org 에서 파이썬 설치 (설치 첫 화면 "Add python.exe to PATH" 꼭 체크)
2. 이 폴더를 C:\chamdom_bot 처럼 짧은 경로에 두기
3. 업비트 Open API 키 발급 (가이드 문서 참고, 이 PC의 IP 등록, 출금 권한 금지)
4. https://btypenine.github.io/chamdom/ 에 본인 구글 계정으로 로그인 → 'PC 봇 연결 코드' 복사
5. bot_config.env.example → bot_config.env 로 이름 바꾸고 키·연결 코드 붙여넣기
6. start_bot.bat 더블클릭 → 창은 닫지 말고 최소화
7. 폰에서 같은 대시보드 주소로 상태 확인

처음에는 TRADE_MODE=paper(모의매매)로 시작합니다. 실제 주문은 live 로 바꾼 뒤부터.
수익을 보장하지 않습니다. 잃어도 괜찮은 소액으로만 쓰세요.
